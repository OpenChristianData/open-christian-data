How Open Christian Data works

Open Christian Data collects Christian texts for reading, research, and AI projects. We convert texts from different source formats into TEI, our common format, and verify their accuracy against the originals. From these copies, we prepare files that let software work with individual verses, sermons, or reference articles, including their source details, credits, and terms of use.

Accepting a copy into the library

Record the decision to use this TEI copy as the library’s master text. The acceptance identifies the exact file, who accepted it, the verification supporting the decision, and any omissions or unresolved problems that someone using it should know about.
→
Install the accepted TEI copy so the export programs can find and read it. The installer saves the text and its library records and keeps the previous version available if an update needs to be reversed.ocd_kernel/tei/install_accepted.py
→
Generate text files for other software from the library’s master TEI copy. When a correction is accepted, replace the master copy and regenerate the affected files from it.

↓

→
Store the entries in JSONL and Arrow for research and AI software. JSONL has one entry per line; Arrow organizes the data in columns. Progress is saved after each edition so an interrupted job can resume.
