# v1.0.0 — The De-slop release

We've rebuilt the pipeline from the ground up and reprocessed every work in this release, making substantial corrections along the way. We did this so you can have much more confidence in the data you download.

**852 works · 881 copies · more than 153 million words.**

This release includes the TEI master copies, with each edition in a separate file, and a complete collection catalogue with publication details, source links, credits, and reuse terms. The visual verification workbench lets agents compare their copies with the sources and check the words and layout.

The [Hugging Face dataset](https://huggingface.co/datasets/OpenChristianDataOrg/open-christian-data) has 711,061 records across 13 categories, available as JSONL and typed Arrow downloads. Existing users should follow the [migration guide](https://huggingface.co/datasets/OpenChristianDataOrg/open-christian-data/blob/v1.0.0/releases/v1.0.0-migration.md): category names and fields have changed. Pin `revision="v1.0.0"` when loading this version.

## Downloads

- [TEI master copies](https://github.com/OpenChristianData/open-christian-data/releases/download/v1.0.0/open-christian-data-v1.0.0-tei.zip): 881 individual XML files, plus the bibliography, source notices, and a checksum manifest.

The texts have different reuse terms; see the [source notices](https://github.com/OpenChristianData/open-christian-data/blob/v1.0.0/docs/SOURCE_NOTICES.md). The code, schemas, and tools remain under CC BY-NC 4.0.
