# Open Christian Data: published data terms

This dataset uses the applicable terms for each selected text. It is not
released under one blanket CC0 dedication. This document explains the release's
existing per-item policy; it does not grant new rights or replace a source license.

Read each record's `license` and its [source notice](SOURCE_NOTICES.md). An original work,
translation, edition, transcription, database, or other digital contribution
can have different terms. Historical public-domain status can depend on the
jurisdiction. A provider's designation is not a worldwide rights guarantee.

The selected release includes qualified public-domain text and supported source
licenses and dedications, including CC0, the Unlicense, CC BY, and CC BY-SA
where identified in the notices.
These terms apply to their identified items and layers, not automatically to
every other text in the collection. Preserve applicable attribution, notices,
change statements, source availability, or share-alike requirements.

The source notices provide the supported scope and qualifications for the
selected copy. Consult them before redistributing or adapting a text. This
policy summary does not replace their complete license text or conditions.

The repository's software, schemas, and tooling have separate CC BY-NC 4.0
terms. Those code terms do not turn the published dataset into a single
CC BY-NC licensed text collection.
