# Public launch roadmap

## Wanted list

When OCD goes public, add a community "wanted list" — texts or datasets the project would like contributions on.

Standard Ebooks has a similar wanted list that drives volunteer contributions. A public wanted list lets the community signal gaps and self-organise around acquiring/cleaning priority texts (e.g. ISBE, missing patristics, non-English confessions).

Keep a running list of wanted items as the project matures. Draft the wanted list page before public launch so it's ready on day one.
