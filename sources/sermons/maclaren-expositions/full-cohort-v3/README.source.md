# Maclaren Expositions structured cohort v3

This nonaccepted review package represents the exact ordered set of fifteen
retained Project Gutenberg TXT members for `maclaren-expositions` as one
top-level work and one TEI. It preserves all 339,526 physical source lines,
26 source-attested parts, and the source-local hierarchy recorded in
`source-structure-map.json`.

The 1,444 mapped markers are provisional source-structure observations:
1,386 exposition heads, 43 book-section heads, 14 internal subsections, and
one verse-column label. Twenty-eight exposition titles that are not exact
contents-text matches retain their adjacent scripture epigraphs. Source
spelling and typographic variants are preserved.

Each complete retained Project Gutenberg member, including its attribution
and license text, remains part of the source and the TEI. This notice is not a
rights opinion or clearance. Certain print-edition lineage, human acceptance,
print collation, rights clearance, public selection, and publication remain
separate and unrecorded.
