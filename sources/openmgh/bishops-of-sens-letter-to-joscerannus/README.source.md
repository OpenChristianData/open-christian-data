# Electronic source for the Bishops of Sens letter to Joscerannus

The retained text source is `raw/openmgh/bsb00000829/tei/bsb00000829.xml` (SHA-256 `cb35385e4e4ba87f80a002452a527527866322af7ccea7f23f366735e46df989`). The ZIP is its acquisition package. This work selects the first numbered letter in source division 17, from `bsb00000829_00657_19` through the complete closing line `bsb00000829_00662_20`. The next numbered line and Joscerannus's response remain outside this work. The preceding Ivo letter ends before this heading; its separate catalog identity and review status are unchanged.

The retained electronic header asks anyone distributing the file or a derivative to name Monumenta Germaniae Historica (MGH) and the Bavarian State Library, Munich (BSB). It identifies added MGH/BSB annotations as CC BY 4.0 and describes the underlying text as believed to be in the public domain. These are source statements; they do not independently clear rights for a release. No print witness was collated, and human acceptance and publication remain separate.
