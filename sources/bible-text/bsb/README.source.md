# Berean Standard Bible source

This candidate is bound to the retained native JSON member
`raw/bible_databases/formats/json/BSB.json` from the bible-databases source
repository. The retained source is the authority for its translation marker,
book/chapter/verse order, source numbers, and verse text.

The local work configuration records the observed Berean Standard Bible
identity, source edition claim, and CC0 claim. Those metadata and rights claims
remain separately reviewable; this file is source attribution evidence, not a
rights decision or publication authorization.

The candidate preserves all 66 books, 1189 chapters, and 31102 verse objects,
including the 16 source verse objects whose text is empty. The JSON files under
`data/bible-text/bsb/` are downstream segmentation and were not used as TEI
authority. This reconstruction is a nonaccepted candidate and is not approved
for publication.
