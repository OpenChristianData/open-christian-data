# King James Version retained-source attribution

This ticket-local reconstruction is sourced from the retained
`raw/bible_databases/formats/json/KJV.json` member in the Open Christian Data
workspace. The configured source repository is
<https://github.com/scrollmapper/bible_databases>.

The retained JSON translation marker is preserved exactly as source metadata:
`KJV: King James Version (1769) with Strongs Numbers and Morphology and CatchWords`.
The verse objects used by this reconstruction contain only the retained `verse`
and `text` fields. The candidate therefore preserves the exact verse strings and
does not invent Strong's, morphology, or catchword fields.

The local work configuration describes the source as the public-domain King
James Version, with the 1769 Blayney standard text as the edition claim. That
metadata claim is recorded as source/config evidence; this candidate does not
constitute human rights clearance, human acceptance, promotion, or publication
authorization.
