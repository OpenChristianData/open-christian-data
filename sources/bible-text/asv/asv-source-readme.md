# American Standard Version: retained JSON reconstruction

This nonaccepted candidate reconstructs the complete retained member
`raw/bible_databases/formats/json/ASV.json`, SHA-256
`0851e73ac46ae7ccaf1a8bb44beb359295df5eca04a578ea4d448eb7a641f9ae`.
Its own label is `ASV: American Standard Version (1901)`.

All 66 books, 1,189 chapters, and 31,102 verse carriers retain source-native
order, labels, wording, and trailing whitespace. Book names become headings;
chapter and verse numbers become explicit TEI numbers. XML escaping represents
literal text; no inferred inline markup, OSIS mapping, or editorial correction
is introduced. Source JSON syntax becomes the declared hierarchy. The complete
scalar accounting records source pointers and TEI targets without excluding text.

This is the complete retained JSON witness, not proof of a complete physical
1901 printing. Prefaces, original page layout, marginal apparatus, and the exact
physical edition are unassessed. Publication dates, contributors, and rights
are not inferred from another Bible translation. The existing config is bound
as contextual work identity, not adopted wholesale as verified metadata.

The config identifies the provider as scrollmapper/bible_databases:
https://github.com/scrollmapper/bible_databases
That attribution is retained as a config claim. Source correction, rights
clearance, human acceptance, accepted-master promotion, and publication remain
separate decisions. No such decision is made by this package.
