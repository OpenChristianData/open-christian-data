# Catholic Encyclopedia: retained New Advent web witness

Source provider: [New Advent, The Catholic Encyclopedia](https://www.newadvent.org/cathen/).
This route reconstructs a newly retained current web transcription, acquired
beginning September 11, 2026 UTC. Exact response bodies and acquisition receipts
remain under `raw/newadvent/`; the bound manifest, when issued, identifies every
required HTML, image, and stylesheet member by URL, retained path, byte count,
and SHA-256.

The home page contains an original preface as well as navigation. Its linked
letter pages explicitly distinguish partial indexes from full indexes. The
initial acquisition graph includes the home page, all 47 discovered letter and
full indexes, and 11,612 distinct article-shaped targets, including three
source-history pages. Recursive anchor and canonical-link accounting expanded
that set to 11,640 targets and then reached a stable retained-page frontier.
The retained collection contains 11,632 of those targets plus 48 index/preface
pages. Eight target URLs returned HTTP 404. Of 387 declared source images,
378 were retained and nine returned HTTP 404; the declared stylesheet was
retained. Exact failures remain in their acquisition receipts, with no alternate
witness or corrected URL substituted. A stable retained graph does not establish
the unknown content behind unavailable URLs. This route declares a partial
retained cohort: 11,680 retained HTML pages, 378 retained images, and one
stylesheet. It does not declare the entire web collection complete. All eight
missing HTML and nine missing image responses are bound as failed-acquisition
evidence, excluded from included content, and listed as readable TEI gaps.
Displayed unavailable images retain their source alt text alongside the gap.

The bound presentation policy reconstructs the censused static typography of
the retained stylesheet. It does not claim pixel-identical browser layout,
downloaded font identity, or hover/visited-state equivalence. Exact retained
malformed-source mappings preserve block-spanning emphasis, the Dives wrapper,
and the XML-forbidden U+0017 character as an explicit source glyph carrier;
they do not modernize or silently repair the witness.

The catalog anchor `catholic-encyclopedia-vol01` is the existing LIB-025 umbrella
ticket identity. It does not mean that every page in this web collection belongs
to printed volume 1. Article-local citation, author, volume, date, transcription,
dedication, approbation, and publisher statements are preserved where present.
Support/history material remains separately identified by its source page.
Retained citation statements also include Vol. 16 (Index), 1914, and Vol. 17
(Supplement), 1922. For example, the retained Archpriest Controversy page
(16004a.htm) and St. Thérèse of Lisieux page (17721a.htm) carry those statements.
The authorized current-web envelope includes these linked pages; it is not
silently restricted to, or relabeled as, the 15 historical generated volumes.

The retained New Advent pages carry publisher copyright and transcription-credit
statements. Their preservation and technical reconstruction do not independently
establish rights to the carrier or authorize public redistribution. Read each
page's retained publisher and contributor statements before deciding downstream
use. This README accompanies the private candidate as a human-visible provenance
and attribution deliverable; it is not a replacement for those source statements.

The 15 historical generated-volume source-hash claims remain unchanged in the
historical blocker evidence. Their discarded response bytes have not been
recovered, and hashes of this new witness must not be substituted for them.
Generated legacy JSON is not a source authority for this reconstruction.

Candidate generation, source accounting, schema checks, and independent
verification remain distinct from human textual acceptance, accepted-master
promotion, and public publication.

Browser-standard HTML interpretation is distinct from the retained response
bytes. Malformed source names remain explicitly represented in source accounting;
they are not silently repaired into plausible metadata or link targets. Any
unresolved source structure or unavailable indexed member prevents a complete
reconstruction claim.
