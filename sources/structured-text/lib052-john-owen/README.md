# LIB-052 John Owen retained sources

The ten nonaccepted reconstruction candidates in this package are **sourced via [CCEL.org](https://www.ccel.org/)**. CCEL confirmed that Open Christian Data may parse its ThML/XML files to recover underlying public-domain text and asks to be credited for making those files available. CCEL's file and formatting rights remain distinct from the historic works; do not sell CCEL files or derivatives of their formatting.

Some retained headers also state that the electronic base text was extracted from the AGES Digital Library John Owen Collection and include an AGES Software copyright assertion while `DC.Rights` is empty. This technical packet does not resolve that electronic-base-text question. The candidate remains restricted, nonaccepted, and not publication-ready pending human rights, edition, and textual review.

The retained family contains 32 XML files. LIB-052 includes exactly ten. The ten LIB-050 and ten LIB-051 members are excluded, `worship.xml` is excluded for LIB-053, and `raw/ccel/owen/poema.xml` is explicitly unresolved for LIB-090 because it is a retained Latin poem to Cromwell with no frozen WorkCatalog or ticket-map identity.
