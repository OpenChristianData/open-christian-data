# Samson Occom, *A Sermon ... at the Execution of Moses Paul* — Evans-TCP N09814

This source-local route is bound to the Text Creation Partnership's keyboarded
and encoded TEI P5 edition of Samson Occom's 1772 execution sermon, printed and
sold in New Haven by T. & S. Green, identifier N09814 (Evans 12494).
The source-local work identity is `occom-moses-paul-execution-sermon`.

TCP makes the keyboarded and encoded Phase I text available under Creative
Commons CC0 1.0 Universal. TCP also respectfully requests credit and
attribution to the original source; this README preserves that request and the
source links. The commercial Readex/Newsbank page images are not included, and
this route makes no reuse claim for those scans.

The retained transcription contains long-s typography, 32 page milestones,
156 encoded characters, 17 illegible gaps, verse lines, and two nested address
texts. The candidate preserves the TEI P5 bytes exactly. Technical validation
is not human textual, identity, edition, rights, editorial, canonical, or
publication acceptance.
