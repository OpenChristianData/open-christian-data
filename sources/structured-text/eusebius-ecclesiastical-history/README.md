# LIB-028 retained CCEL church histories

This packet reconstructs five exact `div1` roots from retained CCEL Schaff
`npnf201.xml`, `npnf202.xml`, and `npnf203.xml`. The complete selected subtrees
are represented in source order. Document shells, title pages, prefaces,
siblings, and indexes outside those roots are explicitly accounted but are not
silently included as work text.

CCEL permits parsing its ThML/XML for text and asks that users not sell CCEL
files or derivatives of CCEL formatting. Source attribution: Christian
Classics Ethereal Library, [ccel.org](https://www.ccel.org/). The retained
headers state `Public Domain`; that statement is evidence, not a new rights or
publication decision by OCD.

Technical verification is not human textual acceptance or publication
authorization. Publication remains `not_ready`.
