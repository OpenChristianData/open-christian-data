# Jupiter Hammon, *An Address to the Negroes in the State of New-York* — Evans-TCP N15943

This source-local route is bound to the Text Creation Partnership's keyboarded
and encoded TEI P5 edition of Jupiter Hammon's 1787 address, printed in New
York by Carroll and Patterson, identifier N15943 (Evans 20400).

- Item record: https://name.umdl.umich.edu/N15943.0001.001
- Official TCP repository: https://github.com/textcreationpartnership/N15943
- Pinned XML: https://raw.githubusercontent.com/textcreationpartnership/N15943/541a6a41bd35466692aa2576e700caad27347330/N15943.xml
- Upstream revision: `541a6a41bd35466692aa2576e700caad27347330`

The live Michigan item route returned a Cloudflare challenge during the
2026-08-31 acquisition. The retained identity evidence therefore includes the
redacted live response headers and a Wayback snapshot dated 2025-01-11. The
current official TCP repository, pinned XML, and TEI header provide the exact
text and edition bindings; the archived item page is explicitly not presented
as a live-page capture.

TCP makes the keyboarded and encoded Phase I text available under Creative
Commons CC0 1.0 Universal. TCP also respectfully requests credit and
attribution to the original source; this README preserves that request and the
source links. The commercial Readex/Newsbank page images are not included, and
this route makes no reuse claim for those scans.

The retained transcription includes its title page, dedication to the African
Society, public notice, main address, 20 page milestones, 84 encoded-character
markers, one blotted-word gap, numbered counsel, quotations, emphasis,
datelines, signatures, and final `FINIS.` The candidate preserves the TEI P5
bytes exactly. Technical validation is not human textual, identity, edition,
rights, editorial, canonical, or publication acceptance.
