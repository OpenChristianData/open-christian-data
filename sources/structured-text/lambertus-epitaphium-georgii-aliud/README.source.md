# Second Georgius epitaph source and data attribution

Retained source: MGH and Bavarian State Library, Munich (BSB), openMGH SS rer. Germ.73. This is the complete second six-line ALIUD epitaph within the triplex collection; the native internal page marker remains. Other epitaphs are excluded, and the full triplex is not represented.
