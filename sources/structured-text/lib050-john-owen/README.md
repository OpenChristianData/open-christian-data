# LIB-050 John Owen retained sources

The ten nonaccepted reconstruction candidates in this package are **sourced via [CCEL.org](https://www.ccel.org/)**. CCEL confirmed that Open Christian Data may parse its ThML/XML files to recover underlying public-domain text and asks to be credited for making those files available. CCEL's file and formatting rights remain distinct from the historic works; do not sell CCEL files or derivatives of their formatting.

Eight retained headers also state that the electronic base text was extracted from the AGES Digital Library John Owen Collection and include an AGES Software copyright assertion while `DC.Rights` is empty. This technical packet does not resolve that electronic-base-text question. The candidate remains restricted, nonaccepted, and not publication-ready pending human rights, edition, and textual review.

The retained family contains 32 XML files. LIB-050 includes ten. Twenty-one are assigned to LIB-051 through LIB-053. `raw/ccel/owen/poema.xml` is a retained Latin poem to Cromwell but has no frozen WorkCatalog or ticket-map identity; it is explicitly excluded here and surfaced as an unresolved LIB-090 map hole.
