# Edward Stillingfleet — *Origines sacræ* (1662)

This source binding uses the keyboarded and encoded EEBO-TCP Phase I text
`A61580.0001.001`, retained from the Text Creation Partnership repository at
commit `dcb5044e68c0577d5269e9a0cbf90f3b9081057c`.

EEBO-TCP identifies the source as the 1662 London edition printed by R. W. for
Henry Mortlock, transcribed from the Bristol Public Library copy represented by
EEBO image set 53276. The TEI header states that the Phase I transcription is
available under the Creative Commons CC0 1.0 Universal dedication and requests
credit to the original source. Accordingly, derivative use should credit the
Early English Books Online Text Creation Partnership and preserve the TCP
identifier and source link.
