# Chrysostom liturgy source and release notice

The accepted electronic edition is the complete 1866 anonymous English translation transcribed by Wikisource contributors. The retained acquisition includes all 118 scan positions, the source export and rendered transcription, and the two original images. Its exact scope and technical acceptance are recorded in the work's acquisition and acceptance sidecars.

The source labels the anonymous 1866 edition public domain in the United States and in jurisdictions whose anonymous-work term is no more than 95 years. Wikisource's [licensing policy](https://en.wikisource.org/wiki/Wikisource:Licensing) licenses contributor text under CC BY-SA 4.0 and the GNU Free Documentation License. This release preserves CC BY-SA 4.0 for the contributor transcription; it does not claim worldwide public-domain status or CC0.

The visible release credit, license link, contributor-history route, and change description are in [`data/liturgies/chrysostom-divine-and-sacred-liturgy/README.md`](../../../data/liturgies/chrysostom-divine-and-sacred-liturgy/README.md).
