# Count Ludewic reply to Walram retained source

Source: Monumenta Germaniae Historica (MGH) and Bavarian State Library, Munich (BSB), retained openMGH electronic MGH Ldl2, bsb00000829. ## Source sender and dictator context

Stephano, qui et Herrandus, Halverstadensi episcopo, eas tradidit legendas, rogavitque
