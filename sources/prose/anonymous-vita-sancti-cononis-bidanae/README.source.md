# Conon source and release notice

The accepted edition is the complete PTA Greek critical-edition TEI member `pta0041.pta001.pta-grc1` at pinned repository commit `ef861ab391ea35c5d85b41dd8d7ba2bf65530b21`, edited by Philipp Pilhofer. Its source header identifies the Berlin-Brandenburgische Akademie der Wissenschaften as authority, PTA as distributor, and states a file-level CC BY-SA 4.0 license.

The distinct PTA manuscript transcription (`pta-Mss`, CC BY-NC-SA 3.0) is excluded from this work. The accepted TEI adds source/work bindings and a revision entry in its header; the source text is retained. OCD projects that accepted TEI into the prose row schema, so the released record is not the original XML file. The downloader-visible notice is [`data/prose/anonymous-vita-sancti-cononis-bidanae/README.md`](../../../data/prose/anonymous-vita-sancti-cononis-bidanae/README.md) and must accompany any selected release item.
