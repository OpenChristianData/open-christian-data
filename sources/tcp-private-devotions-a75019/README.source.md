# TCP A75019 — *Private Devotions for Several Occasions*

This item is the complete retained EEBO-TCP Phase I TEI P5 transcription of
*Private devotions for several occasions, ordinary and extraordinary* (London,
1660), A75019, Wing A1161, ESTC R231157, EEBO image set 136899. The TCP
metadata names Richard Allestree; its print-source note specifically says
“By Richard Allestree.--Wing (CD-ROM edition).” We record Allestree as an
attributed author, not as an independently established authorial fact.

Official TCP item: https://github.com/textcreationpartnership/A75019
Retained XML source: https://raw.githubusercontent.com/textcreationpartnership/A75019/master/A75019.xml

The source header applies Creative Commons CC0 1.0 Universal to TCP’s keyboarded
and encoded Phase I edition and asks users to credit and attribute TCP. This
README supplies that source credit. The retained package contains the TEI text
and source receipt; its `pb/@facs` pointers refer to ProQuest page images that
are not retained or licensed here. No claim of page-image rights follows.

The candidate reproduces the retained TEI XML byte for byte. It is not a
collation with the 1660 print witness. TCP describes sampled proofreading and
remaining possible keying errors; encoded `gap` and `g` elements remain unchanged.
CVW visual comparison, human textual and editorial acceptance, broader rights
review, and publication authorization remain pending. The other three TCP
items in manifest row L788 are separate works and are outside this package.
