# Evangelische Gezangen (1806): source and release notice

The retained DBNL XML electronic witness supplies the accepted complete TEI master. The selected text rows contain only the 192 body hymns. The full private master also retains the title, prefaces, registers, errata, display markup, and score-image references. The downloader-visible scope and credit are in `data/hymns/evangelische-gezangen-1806/README.md`; include that notice with the selected release.

DBNL identifies the first edition as Johannes Allart, Amsterdam, 1806, using the Ghent University Library copy BL 7693. Its title-specific terms mark the work *Auteursrechtvrij*, permit download and further digital or print distribution, and recommend the credit “geraadpleegd via DBNL (KB, nationale bibliotheek).” This is a scoped statement about this title and selected text, not a claim about DBNL's whole collection or separate images.

DBNL's 2013 colophon identifies three interventions. The page 151 lacuna marker occurs in hymn LXXIII and is retained as an explicit marker of illegible historical text, without reconstructed wording. The page 352 register supplementation and page 386 spelling correction are outside the selected hymn rows. The electronic witness has not been collated against print page scans.
