# King James Version: retained electronic verse-text notice

The paired, downloader-visible notice is `data/bible/kjv/README.md`.

This private, U.S.-qualified preparation contains the 66 ordered books, 1,189 chapters, and 31,102 verse strings of the existing accepted KJV electronic witness from [Scrollmapper bible_databases](https://github.com/scrollmapper/bible_databases). Each retained verse object has only `verse` and `text` fields. The source translation marker mentions Strong's numbers, morphology, and catchwords, but none is present in the retained verse objects or represented as extra public content. Source strings and boundaries remain unchanged. The marker calls the version “1769”; it does not prove exact collation to a particular Blayney printing or the identity of later electronic editors.

The historical King James Version wording was published in 1611 and its commonly labeled 1769 form long before the current [U.S. copyright term cutoff](https://www.copyright.gov/circs/circ15a.pdf). The qualified U.S. public-domain statement here concerns that historical wording and source-derived verse positions, not every right in the electronic file, later apparatus, or other territories.
