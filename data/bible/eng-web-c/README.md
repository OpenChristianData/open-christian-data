# World English Bible (Catholic): retained-source notice

This private offline dataset selection represents the retained eBible.org **World English Bible (Catholic)** USFM edition. It has 73 books in Catholic order, 1,328 chapters, and 35,408 source verse carriers. The accepted text preserves the source's words, headings, notes, and line pointers; the tabular release is a reading projection of that one electronic edition. It is not a claim about every Bible canon, another WEB edition, or a physical printing. Four source notes remain in the ordered structure but are omitted from the readable verse text, and source-native blank verse slots are retained.
