# American Standard Version: retained electronic witness

The retained source labels itself ASV: American Standard Version (1901). This release contains the complete acquired Scrollmapper bible_databases JSON electronic witness: all 66 books, 1,189 chapters and 31,102 source verse records. It preserves 4,143,242 literal characters, including 16 nonempty whitespace-only slots; there are no true-empty source strings. No missing verse is guessed or filled.

The acquired source has translation and books fields; it supplies no verified contributor allocation, imprint or original apparatus. The existing local configuration describes the translation as public domain and associated with 1901 and the American Revision Committee; these remain configuration claims, not newly verified primary print metadata or independent rights clearance. The retained repository README confirms the ASV provider label. The accepted TEI and source are unchanged. Human textual/visual acceptance, physical 1901 print completeness, rights clearance and public publication remain separate.
