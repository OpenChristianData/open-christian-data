# A Body of Divinity: source credit and bounded text scope

Sourced via [CCEL.org](https://www.ccel.org/ccel/watson/divinity.html). The retained electronic source names Thomas Watson as author and Jon Van Hofwegen for **Markup**. Its brief CCEL staff description is by Kathleen O'Bannon; that description is outside the accepted text and the selected public rows. The accepted text includes the “Brief Memoir of Thomas Watson” credited in the text to C. H. Spurgeon.

The ten selected records preserve the complete accepted ThML body in source order: title, memoir, Watson text divisions, and the Scripture index. The source itself labels the index “automatically inserted scripRef index.” It is delivered as source-derived book headings, reference labels, and links, not described as a printed historical index. The public transform removes the CCEL presentation class `Body` and replaces four source index style classes with plain semantic index roles. All readable text, record identities, reference labels, source links, and link targets remain unchanged. The original classes remain in an exact private inverse receipt. No modern staff description, image, stylesheet, or CCEL file formatting is included in the selected public content.
