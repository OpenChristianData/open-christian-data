# BCP 1928 Collects: source and rights notice

These collects come from 100 retained electronic propers pages identified as the 1928 Book of Common Prayer on [EpiscopalNet](https://www.episcopalnet.org/1928bcp/propers/). Retained page footers credit episcopalnet.org and carry the lines “Traditional Anglicanism in the 21st Century” and “That God in all things may be glorified through Jesus Christ.” EpiscopalNet is credited as the electronic source provider; an individual transcriber and a specific printed exemplar have not been established for this selection.

This partial selection has 100 source-derived collects in retained inventory order. The retained Trinity 23 and Trinity 24 pages contain no collect, so neither missing collect is supplied here. Historical claims of two imported print-scan collects are not part of this accepted electronic witness. Epistles, Gospels, hymns, page navigation, and website scripts are outside this collect selection. This is not a complete printed 1928 prayer book or a claim that the electronic selection exhausts every proper.

The retained HTML also contains Superstats code comments naming Copyright 2008 or 2019 MyComputer.com, Inc. The analytics code is not distributed as selected collect text. An earlier source configuration called the underlying 1928 prayer book text public domain; that is a historical configuration claim, not independent clearance for this electronic expression. Electronic-file and formatting rights, human textual acceptance, print collation, and public distribution authorization remain unresolved. This package is a private offline technical release.
