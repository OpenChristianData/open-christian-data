# Torrey's New Topical Textbook: selected historical text and source credit

This selection delivers the existing 623 ordered topics and 23,549 literal
definition strings retained from [JWBickel/BibleDictionaries](https://huggingface.co/datasets/JWBickel/BibleDictionaries).
Every source string and repeated heading stays in its retained order. Scripture
labels remain literal text; no new scripture targets or subtopics are inferred.

The historical-wording comparison uses [CCEL's Torrey concordance](https://www.ccel.org/ccel/torrey/ttt),
which CCEL identifies as published in 1897. All 623 topic headings match in
order; all retained definition word and number sequences match that separate
electronic text. Comparison ignores case, punctuation, whitespace and paragraph
segmentation; it does not change delivered wording. The last retained topic,
Zebulun, lacks one paragraph present in CCEL: the country being blessed with
Christ's presence and instruction, citing Isaiah 9:1 and Matthew 4:13-15. This
paragraph has not been inserted from an unaccepted source. The retained electronic
witness remains usable and bounded; it is not a complete historical print claim.

Credit R. A. Torrey for the historical concordance and JWBickel/BibleDictionaries
for this retained structured witness. CCEL is the separate historical-wording
comparison provider. Its modern staff description and formatting are not copied
into this dataset. The comparison header's rights and print-publication fields
are blank; no CCEL public-domain declaration is invented. The provider has no
bound text license, so no provider grant or CC0 dedication is asserted. The
selected terms identify public-domain historical wording in the United States,
with these source and completeness qualifications. This private preparation
does not assert exact print collation, worldwide rights or public-upload
authorization. Keep this credit and qualification with the selected records.
