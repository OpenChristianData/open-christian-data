# Source credit: Didache, Lake translation

This English electronic witness of the *Didache* is based on the
[Wikisource Didache (Lake translation) page](https://en.wikisource.org/wiki/Didache_(Lake_translation)).

including the prayers, chapter divisions, and footnotes. The work is recorded
under Open Christian Data's existing `didache-prayers` identity.
